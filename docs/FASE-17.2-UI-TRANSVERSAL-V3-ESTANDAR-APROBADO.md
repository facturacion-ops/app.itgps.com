# IT GPS APP — FASE 17.2 UI TRANSVERSAL V3

## Estándar visual aprobado

Todos los formularios Nuevo/Editar usan un modal grande centrado con:

- Encabezado de ficha consistente.
- Sidebar interno oscuro con secciones numeradas.
- Sección activa resaltada en verde.
- Área de contenido con scroll independiente.
- Formularios organizados en 2 o 3 columnas según el ancho disponible.
- Títulos de sección sobre sus campos.
- Barra inferior sticky con Cancelar y Guardar.
- Responsive para pantallas pequeñas.

## Alcance

La corrección es exclusivamente visual. No modifica la lógica de negocio ni el esquema de SQLite y no requiere `db:init`.

## Referencia

La referencia visual aprobada por el usuario es la maqueta de Nuevo cliente corporativo generada el 30 de agosto de 2026.
