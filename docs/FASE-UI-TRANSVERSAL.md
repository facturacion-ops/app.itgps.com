# FASE TRANSVERSAL — UI IT GPS APP v1

## Objetivo
Unificar la experiencia visual de IT GPS APP sin modificar la lógica de negocio, SQLite, API, permisos o multiempresa.

## Línea visual
Command Center: identidad azul oscuro + verde IT GPS, navegación agrupada, dashboard operativo, tarjetas KPI, tablas limpias, formularios consistentes y responsive.

## Referencias de inspiración
- Tuesday: gestión visual y simplicidad.
- DataFlow: dashboards, datos, actividad y reportes.
- CreatorFlow: organización visual y futuros modos Lista/Kanban/Calendario.

## Aplicado en v1
- Sidebar agrupado por Principal, Comercial, Operación, Información, Gestión y Administración.
- Marca IT GPS APP con subtítulo Command Center.
- Header con empresa, rol, usuario y estado del sistema.
- Dashboard operativo con KPIs y accesos rápidos.
- Cards, tablas y botones con jerarquía visual consistente.
- Responsive para escritorio, tablet y móvil.

## Regla
Esta fase es exclusivamente transversal de UI. No cambia las rutas API ni el modelo de datos de las fases aprobadas.
