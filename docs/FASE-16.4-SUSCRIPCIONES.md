# FASE 16.4 — Suscripciones

Una suscripción representa la contratación de un plan por un cliente. Relación: Cliente → Suscripción → Plan → Servicio.

Incluye código, cliente, plan, fechas, cantidad, precio, descuento, día de facturación, renovación automática, estado y observaciones. Los estados operativos de esta fase son Activa y Suspendida; el registro se conserva para trazabilidad.
