# FASE 12.2 — Centro Operacional V2

## Estado
Mejora visual y de experiencia de usuario sobre la Fase 12.2 funcional.

## Cambios
- Se agregó **Limpiar filtros**.
- Limpiar filtros restablece búsqueda, empresa, conectividad, estado operacional y relación.
- Se reforzó la jerarquía visual de los 8 indicadores mediante colores por estado.
- El estado operacional de cada fila se presenta como etiqueta visual diferenciada.
- **Ver ficha** pasó de panel lateral a modal centrado con fondo oscurecido.
- La ficha muestra encabezado, conectividad, estado operacional, relación, última información y observaciones.
- Se mantiene el cierre superior y se agrega **Cerrar ficha**.

## Base de datos
Esta versión no agrega ni modifica tablas y debe ejecutarse utilizando la **BD actual**.
No ejecutar `npm run db:init` para instalar esta versión.
